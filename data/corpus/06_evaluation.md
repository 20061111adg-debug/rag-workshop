# 人事評価制度ガイド

> **【ダミー文書】** これは RAG 学習用の架空の文書です。実在の規程ではなく、記載内容に効力はありません。

## 1. 評価の全体像
当社の人事評価は「**業績評価**」と「**行動評価**」の2軸で構成される。
最終評価は業績評価60%、行動評価40%の加重平均で算出する。

## 2. 評価サイクル
評価は年2回、上期（4月〜9月）と下期（10月〜3月）で実施する。
- 目標設定: 期首の1ヶ月以内（4月末、10月末が締切）
- 中間レビュー: 期の中間（7月、1月）に上長と1on1で進捗を確認
- 自己評価: 期末の翌月10日まで
- 上長評価: 期末の翌月20日まで
- 評価会議（キャリブレーション）: 期末の翌月下旬
- 本人へのフィードバック面談: 期末の翌々月10日まで

## 3. 目標設定のルール
目標は3〜5個とする。それ以上は焦点が分散するため認められない。
各目標には重み（合計100%）と、達成基準を定量的に記述すること。
「頑張る」「意識する」等の定性的表現のみの目標は差し戻す。

目標の種別は以下の3つに分類する。
- **成果目標**: 担当業務における定量的な成果。全体の60%以上を占めること。
- **挑戦目標**: 未経験領域への挑戦。達成度が低くても減点しない。
- **育成・貢献目標**: チームや組織への貢献、後進の育成、技術発信など。

技術職においては、「新しい技術領域を自ら学習し、その成果を社内へ共有する」取り組みは
挑戦目標および育成・貢献目標の双方に該当しうる。この場合はいずれか一方に計上すること。

## 4. 評価段階
評価は S / A / B / C / D の5段階とする。標準はBである。
S評価は各部門の対象者の5%以内、A評価は20%以内を目安とする（相対分布の目安であり厳格な枠ではない）。
2期連続でD評価となった場合は、人事部を交えた改善計画（PIP）の対象となる。

## 5. 行動評価の観点（バリュー評価）
当社の5つのバリューに沿って評価する。

1. **顧客起点**: 意思決定の理由を顧客価値に接続できているか
2. **Ownership**: 職掌の境界を理由に問題を放置していないか
3. **Learn & Share**: 学んだことを個人に閉じず、組織の資産にしているか
4. **誠実さ**: 悪い情報を早く正確に共有しているか
5. **простота（シンプルさ）**: 複雑さを持ち込まず、本質的な解法を選べているか

## 6. 評価結果の処遇への反映
評価結果は次期の基本給改定および賞与に反映する。
賞与は基準額に評価係数（S:1.5 / A:1.2 / B:1.0 / C:0.8 / D:0.6）を乗じて算出する。
基本給改定は年1回、下期評価の確定後（4月）に実施する。

## 7. 評価に対する異議申立て
フィードバック面談から10営業日以内に、人事部へ書面で申し立てることができる。
人事部は申立てから20営業日以内に、上長とは別の管理職を交えて再検討を行い、結果を通知する。
